# Shaping

This file is the body of the `shaping` module. `crucible help` names it and does not execute it, does not read it into the menu, and does not create a file.

The path is `modules/shaping/SKILL.md` relative to the engine root: the installed program directory when you ran `.crucible/<program>/crucible`, or the engine checkout when you ran the repo-root `./crucible` wrapper. It is not under `$HOME` and it is not in the target repository root.

When the help menu shows the shaping row, read this file after the problem is bound (`crucible cycle problem FILE`) and before `crucible cycle problem FILE --next`. State a bounded outcome, the non-goals, and what would falsify the problem. Do not write a file. Do not dispatch, adopt, drive, or walk.

`writes` is empty. This module creates no files.
